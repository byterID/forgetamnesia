# ForgetAmnesia

Личный календарь и финансовый ассистент в одном приложении.
Запиши событие — его стоимость сразу попадёт в прогноз расходов. Внеси траты — увидишь,
на сколько месяцев хватит денег без нового дохода и когда накопишь на цель.

> Статус: проектирование завершено, разработка по плану `docs/PLAN.md`.

## Что умеет (целевое состояние)

**Финансы**
- Несколько банков, карт, валют, крипта, инвестиции, кредитка, заблокированные деньги (ИИС, депозиты).
- Общий капитал в основной валюте, «доступно сейчас» и **запас прочности** (месяцев без дохода).
- Ежедневные курсы валют и крипты, ручная правка курса, исторический курс на каждую операцию.
- Обязательные платежи, цели с виртуальным резервированием, прогноз в трёх сценариях.
- Норма сбережений с оценкой и советы: сокращать расходы или искать доход.
- Ввод трат: вручную, шаблонами, повтором, импортом выписок, из банковских уведомлений (Android).

**Календарь и задачи**
- События и задачи с горизонтами («сегодня», «до завтра», «на неделе», «на подумать»), вычисляемыми из дедлайна.
- Событие с ожидаемой тратой создаёт плановую операцию; после события — подтверждение в один тап.
- Напоминания через выгрузку в отдельный Google-календарь (позже — локальные уведомления на Android).
- Быстрая запись за 3 секунды: ярлык на иконке, «Поделиться», разбор фраз вида «театр сб 19:00 2х5000 драм».

**Платформы**: PWA (телефон и компьютер), Android-оболочка на Capacitor, десктоп-раскладка.

## Архитектура в двух словах

```
UI (React) ──► Domain (чистый TS) ──► Dexie (IndexedDB) ──► Op-log ──► Google Drive appDataFolder
                                                         ◄── слияние журналов других устройств
```

- **Local-first**: всё работает офлайн, запись мгновенная.
- **Без бэкенда**: данные пользователя хранятся только на его устройствах и в его Google Drive (скрытая папка приложения).
- **Синхронизация**: каждое устройство пишет только свой журнал операций, слияние по HLC, снимки для компактности.
  Подробно — `docs/spec/sync.md`.

## Стек

React + TypeScript + Vite + vite-plugin-pwa · Dexie · Zustand · Tailwind + shadcn/ui · Recharts ·
decimal.js · rrule · Vitest · Playwright · Capacitor (Android).

## Быстрый старт

```bash
pnpm install
cp .env.example .env        # затем заполнить VITE_GOOGLE_CLIENT_ID
bash scripts/setup-wizard.sh   # (один раз) мастер: проект Google Cloud, OAuth-клиенты, Cloudflare Pages
pnpm dev                    # http://localhost:5173
pnpm test                   # unit
pnpm lint && pnpm typecheck && pnpm build
```

Переменные описаны в `.env.example`. Prod-клиент задаётся в настройках Cloudflare Pages,
файл `.env` не коммитится.

## Конфиденциальность

Приложение не имеет сервера и не видит данных пользователя. Используются scope'ы Google
минимального доступа: `drive.appdata` (только своя скрытая папка) и `calendar.app.created`
(только календари, созданные приложением).
