- **Этап**: M1 (доменное ядро) реализован, PR #24 (`m1-domain-core` → `m0-skeleton`, поверх невлитого PR #14). Тикеты #15–#23 сделаны, закроются при вливании в `main`.

- **Что есть** (`src/domain`, чистый TS, чистота под ESLint):
  - `money/` — `Asset`, `Money`, разбор ввода, формат через `Intl`, арифметика, банковское округление (`Dec`).
  - `fx/` — `Rate`, выбор курса на дату, конвертация через USD (`convert`, `convertExactOn`).
  - `accounts/`, `categories/` (стартовый набор с постоянными id), `transactions/` (инварианты, `fxResult`, `balanceEffects`).
  - `balance/` — `positions`, `netWorth`, `availableNow`, `reconcile`.
  - `src/db` — Dexie v2 (`accounts`, `transactions`, `categories`, `rates`), репозитории: одна точка записи `commit` + хук `onWrite` (для `Op` в M2), надгробия.
  - 171 тест; 100% веток в `money` и `fx` (порог в `vite.config.ts`); фикстура `tests/fixtures/account-state.json`.
- **Ждёт пользователя**:
  1. Влить PR #14 (M0), затем PR #24 (M1) — после вливания #14 PR #24 перенацелится на `main`.
  2. Подтвердить деплой в прод с `main` (#12).
  3. Разрешение на спайки S1, S2, S3 (сеть, тестовый Google-аккаунт).
  4. **Явный ответ по отступлению от ADR-004**: id стартовых категорий и курсов детерминированные, а не UUID v7 (ADR-033, ADR-034).
  5. Формула `Лист1!B9` (ADR-035): входит ли «Долг», как учитывается «Крипта».
  6. `provisional` на подтверждение: ADR-020…036.
  7. Дописать `fast-check` в «Стек» `CLAUDE.md` (агент этот файл не правит).
- **Отложено из M1**:
  - `openingDate` пока справочное: баланс = остаток + все операции независимо от даты (ADR-032).
  - `netWorth` не учитывает `valuation` инвестсчёта — M7 (ADR-020/032).
  - `IsoDate` — обычная строка, без брендированного типа; `WriteEvent.before/after` — `unknown` (уточнить в M2).
  - Репозитории читают таблицы целиком (`list()`); выборки по периодам — в M3/M5 по бюджету `nfr.md`.
  - Настройка «основная валюта» и её хранение — M3.
