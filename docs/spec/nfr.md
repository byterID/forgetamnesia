# SPEC — нефункциональные требования (для всех этапов)

## N1. Производительность (критерии приёмки, проверяются в CI)
- Первый экран < 2 с на среднем Android по 4G (Lighthouse mobile, throttling по умолчанию): LCP < 2.0 с, TBT < 200 мс.
- Повторное открытие установленной PWA < 1 с (данные из IndexedDB, оболочка из кэша Service Worker).
- Отклик на ввод < 100 мс (INP); сохранение операции в Dexie < 50 мс.
- Начальный JS ≤ 200 KB gzip. Лениво: Recharts, SheetJS, парсер фраз, rrule, экраны аналитики/импорта/настроек.
- Списки > 200 элементов — виртуализация.
- Синхронизация и курсы — никогда не блокируют UI.
- CI: `size-limit` на бандл + Lighthouse CI на preview; регрессия → красный PR.

## N2. Надёжность данных
- `navigator.storage.persist()` при первом запуске.
- Миграции Dexie — только вперёд, каждая с тестом на фикстуре предыдущей версии.
- Полный JSON-экспорт доступен всегда (настройки).
- Ошибки — в локальный журнал (последние 200), экспорт для отладки. Никакой внешней телеметрии.

## N3. Безопасность и приватность
- Нет сервера с данными пользователя. Scope'ы: `drive.appdata`, `calendar.app.created`; read-only календари — только по запросу.
- Токены — только в памяти (не в localStorage).
- CSP: `default-src 'self'`; разрешённые connect-src: googleapis.com, accounts.google.com, API курсов.
- Зависимости: `pnpm audit` в CI, Renovate/Dependabot.
- Шифрование журналов паролем (AES-GCM, ключ из PBKDF2/Argon2) — опция M9; без пароля данные не восстановить — предупреждение явное.

## N4. Доступность и UX
- Mobile-first; тач-цели ≥ 44 px; системная тема (светлая/тёмная); `prefers-reduced-motion`.
- Русский интерфейс, все строки — через i18n-ключи (`src/i18n/ru.json`).
- Числа и даты — `Intl` с ru-локалью; сумма всегда с символом валюты.
- Оптимистичный UI: сохранение без спиннеров; отмена удаления 5 с.

## N5. Окружения
- Dev: `localhost:5173`, тестовый Google-аккаунт, OAuth-клиент «ForgetAmnesia Dev».
- Preview: Cloudflare Pages на каждый PR.
- Prod: Cloudflare Pages `main` → свой поддомен `*.pages.dev`. Основной Google-аккаунт — только prod и только после ревью M2.
