# SPEC — десктоп-режим (M10)

ADR-017. Та же PWA, раскладка для ширины ≥ 1024 px. Устанавливается как приложение в Chrome/Edge.

- Боковая навигация вместо нижней панели; главная — сетка панелей (капитал, планы, цели, календарь недели, графики).
- **Таблица операций**: сортировка, фильтры (период, счёт, категория, тег, тип), поиск, массовое редактирование (категория, теги, счёт), массовое удаление с отменой, экспорт CSV/XLSX.
- Редактирование в строке (inline) для суммы, категории, даты.
- Горячие клавиши: `N` трата, `I` доход, `T` перевод, `Q` быстрая запись, `/` поиск, `G then H/O/C/A` — переход по разделам, `?` — справка.
- Календарь — неделя/месяц на всю ширину, перетаскивание записей.
- Графики крупнее, с выбором периода.
Без отдельной сборки и без Tauri.
