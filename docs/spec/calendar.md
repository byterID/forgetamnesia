# SPEC — календарь и задачи (M6)

ADR-008, 009, 010.

## C1. Запись (`Item`)
- Общие поля: заголовок, заметка, теги, `urgent`, `expectedCost?` (сумма, актив, категория, счёт по умолчанию), `parentId?`, `rrule?`, `doneAt?`.
- Событие: начало, конец (по умолчанию +1 ч), весь день, место, напоминания (список смещений: 15 мин, 1 ч, 1 день).
- Задача: дедлайн (дата или дата+время) или без него.
- Подзадачи — один уровень.

## C2. Горизонты (вычисляются, ADR-009)
`overdue` · `today` · `tomorrow` · `week` (до конца 7 дней) · `month` (до 30 дней) · `later` · `someday` (без даты, «на подумать»).
Экран «Задачи»: секции по горизонтам, «Срочно» сверху каждой секции. Свайп вправо — готово, влево — перенести (+1 день / на выходные / выбрать дату / на подумать).

## C3. Связь с финансами
1. `expectedCost` → плановая операция `source: 'item'` на дату записи.
2. «Нужно купить заранее» → `prepTask` «Купить: <заголовок>» с дедлайном (по умолчанию за 2 дня); плановая трата переезжает на дату `prepTask`.
3. После события (или выполнения `prepTask`) → во «Входящих»: «Трата состоялась? <сумма> с <счёт>» → [Да] [Изменить] [Не было].
4. Отмена/удаление записи → плановая операция удаляется (tombstone).
5. В карточке операции — ссылка на запись, и наоборот.

## C4. Выгрузка в Google Calendar
- При первом включении — создать календарь «ForgetAmnesia» (`calendar.app.created`), сохранить его id.
- Каждая запись с временем/датой → событие Google с `extendedProperties.private.faItemId`; напоминания → `reminders.overrides`.
- Изменение/удаление записи → patch/delete события. Очередь выгрузки офлайн-устойчива (как журнал).
- Направление одностороннее. Изменения в Google не читаются обратно (если пользователь правит там — перезапишутся; предупредить в описании события).
- Чтение других календарей пользователя (только отображение занятости) — по отдельной кнопке, инкрементальная авторизация read-only scope.
- Выгрузку выполняет одно «ведущее» устройство? — Нет: идемпотентно по `faItemId` (поиск события по `privateExtendedProperty` перед созданием). Решение проверить в S5.

## C5. Виды
День (лента), неделя, месяц (точки + сумма плановых трат дня), список задач. Плановые траты видны в календаре значком ₽ с суммой.
