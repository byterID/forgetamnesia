# SPEC — быстрая запись (M6)

Цель: от мысли до сохранения < 3 с; запись не теряется ни при каких условиях.

## Q1. Точки входа
- **Ярлык PWA** (`manifest.shortcuts`): «Быстрая запись» → `/capture`, поле в фокусе, клавиатура открыта.
- **Share Target** (`manifest.share_target`, GET): текст/ссылка из любого приложения → черновик.
- Кнопка «+» → «Быстро» (первый пункт).
- M8: виджет Android; M10: горячая клавиша `Q` на десктопе.

## Q2. Сохранение
Нажатие «Сохранить» (или Enter) → `CaptureDraft` пишется в Dexie **до** разбора (< 50 мс) → экран закрывается.
Разбор асинхронный; результат — предпросмотр во «Входящих» с кнопками [Создать] [Изменить].
Если разбор уверенный и пользователь включил «создавать сразу» — запись создаётся без подтверждения.

## Q3. Парсер (`src/services/parser/`, чистый TS, TDD)
Вход: русская фраза. Выход: `{ kind?, title, start?, deadline?, expectedCost?, urgent?, confidence }`.
- Даты/время: «сегодня», «завтра», «послезавтра», «в сб», «в субботу», «20.11», «20 ноября», «через 2 недели», «в 19:00», «вечером» (=19:00). База — chrono-node с ru-локалью, если S4 покажет достаточное покрытие, иначе свой разбор.
- Суммы: «5000», «5к», «2х5000», «5 000 драм/др/AMD/֏», «300 руб/р/₽», «$20». Без валюты — валюта счёта по умолчанию.
- Маркеры: «срочно», «!» → `urgent`; «купить», «оплатить» → задача; время → событие.
- Остаток текста — заголовок.
Набор из ≥ 60 тест-фраз в `tests/fixtures/capture-phrases.ts` (с ожидаемым результатом).
