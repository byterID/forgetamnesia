# SPEC — Android (M8)

ADR-001, 013. Тот же React-бандл в Capacitor. Распространение — APK (сайдлоад), Google Play не нужен.

## D1. Уведомления банков
- `NotificationListenerService` (готовый Capacitor-плагин или свой — решает S6). Разрешение «Доступ к уведомлениям» — экран-инструкция.
- Слушаем только пакеты из списка правил (пользователь выбирает приложения банков из установленных).
- **Правило «по примеру»**: пользователь выбирает пришедшее уведомление → тапает на сумму, валюту, продавца, остаток (если есть) → строится шаблон (regex с именованными группами) + тип (расход/доход/перевод) + счёт.
- Распознанное → `Inbox` (очередь подтверждения). Для правила можно включить автоподтверждение.
- **Дедупликация**: ключ = пакет + сумма + валюта + продавец + окно 10 мин; повторное уведомление и SMS-дубль игнорируются.
- Переводы между своими счетами (уведомление о списании + о зачислении в окне 30 мин с совпадающей суммой) → предлагается как один перевод.
- Нераспознанное уведомление банка → во «Входящих» «Не понял уведомление — создать правило?».
- Банки на телефоне: Ардшинбанк, Fast Bank, Т-Банк, Озон Банк, ВТБ.

## D2. Локальные напоминания
`@capacitor/local-notifications` для напоминаний записей; на Android выгрузка в Google Calendar становится опциональной (настройка).

## D3. Виджет
Виджет домашнего экрана: кнопка «Быстрая запись» + «доступно сейчас». Нативный (Kotlin), открывает `/capture`.

## D4. Биометрия
Блокировка при открытии (биометрия/PIN устройства), таймаут 5 мин в фоне.

## D5. Сборка
GitHub Actions: сборка debug/release APK как артефакт; подпись ключом из секретов.
