## M1 — Доменное ядро (2026-11-16, PR #24, ветка `m1-domain-core`)

Тикеты #15–#23 по кандидатам `docs/plan/M1.md`, по одному коммиту на тикет, затем коммит исправлений ревью (`a7c4ca1`).

**Ревью в контрольной точке**
- code-review (стандарты): `Valuation` конфликтовал с глоссарным `valuation` → `ReportingBasis`; `base` → `baseCurrency`; новые термины записаны (ADR-036); проверка целочисленности денег была только в фабрике `money()` → `assertMoney` на границе записи.
- code-review (спецификация): итоги требовали курс основной валюты даже без валютных счетов (дефект, исправлен через `convertExactOn`); цена USD ≠ 1 принималась (теперь отклоняется); не было поля «сумма в валюте покупки» (добавлено `purchaseAmount`); запрет переопределять ликвидность кредитки противоречил глоссарию (снят).
- thermo-nuclear: одна формула баланса вместо двух циклов; `reconcile` строит корректировку через `createTransaction`; общий тестовый хелпер `tests/support/code-of.ts` вместо десяти копий; упрощён `isoDate`.

**Находки по ходу**
- Dexie подменяет ошибки, чьё `name` совпадает с его собственными (`NotFoundError`), на `DexieError` при откате транзакции — поэтому `RecordNotFoundError`.
- Инструмент записи файлов превращает `\uXXXX` в сами символы; невидимые пробелы в исходниках собираются через `String.fromCharCode`.
- `Intl.NumberFormat.format` принимает точную десятичную строку — форматирование без float.
