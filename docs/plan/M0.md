# M0 — Каркас · Sonnet · middle · ветка `m0-skeleton`

**Цель**: пустое, но «правильное» приложение: собирается, тестируется, деплоится, следит за бюджетом скорости.
**Читать**: `spec/nfr.md`, раздел «Стек/Структура» в `CLAUDE.md`.

## Тикеты-кандидаты
1. Vite + React 19 + TS strict + pnpm; ESLint (typescript-eslint strict) + Prettier; алиас `@/` → `src/`.
2. vite-plugin-pwa: manifest (имя, иконки-заглушки, `theme_color`, `display: standalone`, `shortcuts: [capture]`, `share_target`), SW со стратегией precache оболочки.
3. Tailwind + shadcn/ui (Button, Input, Sheet, Dialog, Toast); системная тема; i18n-заготовка `src/i18n/ru.json` + хук `t()`.
4. Dexie: пустая схема v1 + `navigator.storage.persist()` при старте; dexie-react-hooks.
5. Роутинг (react-router, lazy-роуты) и каркас экранов из `spec/overview.md` с заглушками; нижняя навигация + FAB.
6. Vitest + Testing Library + fake-indexeddb; Playwright smoke (открыть, переключить вкладки, офлайн-перезагрузка).
7. GitHub Actions: lint · typecheck · unit · e2e · build · `size-limit` (≤ 200 KB gzip initial) · Lighthouse CI на preview.
8. Cloudflare Pages: preview на PR, prod на `main`; CSP-заголовки через `_headers`.
9. `.env.example`, `scripts/` из мастера W (если уже есть).

## Готово, когда
- `pnpm dev/test/test:e2e/build` проходят; CI зелёный; preview-ссылка открывается на телефоне и устанавливается как PWA.
- Lighthouse mobile: Performance ≥ 95, PWA installable.
- Офлайн-перезагрузка показывает оболочку.
