# M8 — Android · Opus · high · ветка `m8-android`

**Цель**: автосписание из банковских уведомлений, локальные напоминания, виджет, биометрия.
**Читать**: `spec/android.md`, ADR-001/013, решение S6, фикстуры `tests/fixtures/notifications/`.

## Тикеты-кандидаты
1. Capacitor-проект в `android/`, платформенные интерфейсы `src/services/platform/` (web-реализация = no-op).
2. Слушатель уведомлений (плагин из S6), экран-инструкция разрешения, выбор банковских приложений.
3. Правила «по примеру»: UI выделения полей → генерация шаблона → тест на фикстурах всех 5 банков.
4. Очередь подтверждения во «Входящих», автоподтверждение на правило.
5. Дедупликация и распознавание переводов между своими счетами.
6. Локальные напоминания для записей; настройка «Google Calendar на Android не нужен».
7. Виджет: быстрая запись + «доступно сейчас».
8. Биометрическая блокировка.
9. CI: сборка APK артефактом, подпись из секретов.

## Готово, когда
- На телефоне пользователя: реальная покупка в каждом из 5 банков появляется во «Входящих» ≤ 5 с, дублей нет.
- Напоминание срабатывает при выключенном экране и закрытом приложении.

## Скиллы
`tdd` (шаблоны правил, дедупликация), `diagnosing-bugs` (нативные проблемы), `wizard` (инструкция по установке APK и выдаче разрешений).
