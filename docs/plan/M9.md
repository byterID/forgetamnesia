# M9 — Полировка · Sonnet · middle (шифрование — Fable · high) · ветка `m9-polish`

**Читать**: `spec/nfr.md`, ADR-003/014.

## Тикеты-кандидаты
1. **Шифрование** (Fable · high, отдельная сессия): пароль → ключ (PBKDF2 ≥ 600k итераций или Argon2id через WASM), AES-GCM, `enc: 'aes-gcm'` в конверте; миграция существующих файлов — с явным подтверждением пользователя; предупреждение «забыл пароль = данные не восстановить»; проверка пароля на другом устройстве.
2. Калькулятор ипотеки/кредита: аннуитет/дифференцированный, переплата, «через сколько накоплю первый взнос» (связь с целями).
3. Cloudflare Worker (только если пользователь подтвердит, что окна входа мешают): refresh-токен, кэш курсов.
4. Английская локализация.
5. Аудит производительности на реальных данных за полгода: профилирование, индексы Dexie, мемоизация прогноза.

## Готово, когда
- Шифрование: два устройства, одно включает — второе запрашивает пароль и продолжает синхронизацию; без пароля в Drive нечитаемый payload.
