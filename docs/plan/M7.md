# M7 — Расширенные финансы · Fable · high · ветка `m7-finance-plus`

**Цель**: поведение всех видов счетов из таблиц пользователя.
**Читать**: `spec/finance.md` F6, `CONTEXT.md` («Инвестиции и долги»).

## Тикеты-кандидаты
1. Кредитка: лимит, долг, плановый платёж в `paymentDay`, отражение в капитале.
2. Процентный счёт: модель начисления (решить через tdd: расчётная vs фактический ввод) + ежемесячное создание дохода.
3. Заблокированные счета: дата разблокировки, уведомление во «Входящих».
4. Инвестиции: пополнение = перевод, форма вывода, реализованный результат, ручная оценка.
5. Крипта: монеты × курс, `volatile`, настройка «включать в доступно».
6. Долги «мне должны / я должен» с вероятностью → плановые; «Получено/Отдано».
7. Обновить онбординг и импорт под новые поля.

## Готово, когда
- Тест: пополнение инвестсчёта 100, вывод 60, вывод 70 → реализовано +30, прибыль не появлялась до выводов.
- Капитал на фикстуре листа «Состояние» совпадает (кредитка как минус долг).
