# M4 — Импорт · Sonnet · high · ветка `m4-import`

**Цель**: история пользователя с июня 2025 в приложении + импорт банковских выписок.
**Читать**: `spec/import.md`, ADR-016, ADR-019.

## Тикеты-кандидаты
1. Скрипт `scripts/anonymize-fixtures.ts`: читает `private/*.xlsx`, умножает суммы на случайный коэффициент, переименовывает банки, пишет в `tests/fixtures/` (структура 1:1). **Запускает пользователь**, агент оригиналы не читает. Структура листов описана в `spec/import.md` — этого достаточно, чтобы написать скрипт.
2. Импортёр таблицы «состояние счетов» → начальные остатки, долги «мне должны», вероятные расходы (как черновики плановых до M5).
3. Импортёр помесячной истории → операции-агрегаты; проверочный тест: норма сбережений по месяцам совпадает с листом «Итоги по месяцам».
4. Универсальный мастер CSV/XLSX: предпросмотр, сопоставление колонок, автоопределение формата, выбор счёта.
5. Правила категоризации по подстроке.
6. Дедупликация + «Отменить импорт» по `importBatchId`.
7. Экспорт CSV операций за период.

## Готово, когда
- Импорт фикстур воспроизводит итоги таблицы пользователя (тест).
- Повторный импорт того же файла не создаёт дублей.
- SheetJS в отдельном lazy-чанке, начальный бандл не вырос.
