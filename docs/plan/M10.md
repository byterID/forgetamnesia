# M10 — Десктоп-режим · Opus · middle · ветка `m10-desktop`

Можно делать параллельно с M8 (после M5).
**Читать**: `spec/desktop.md`, ADR-017.

## Тикеты-кандидаты
1. Адаптивная оболочка ≥ 1024 px: боковая навигация, сетка панелей главной.
2. Таблица операций: сортировка, фильтры, поиск, inline-редактирование, массовые действия с отменой, экспорт CSV/XLSX.
3. Горячие клавиши + справка `?`.
4. Календарь неделя/месяц на всю ширину, drag-and-drop записей.
5. Графики с выбором периода.

## Готово, когда
- e2e на 1440×900: найти все траты категории за квартал, сменить им тег массово, экспортировать — без мыши (только клавиатура).
- Мобильная раскладка не изменилась (визуальные снапшоты Playwright).
