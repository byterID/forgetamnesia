# M6 — MVP-3: календарь, задачи, быстрая запись · Opus · high · ветка `m6-calendar`

**Цель**: события и задачи связаны с финансами; запись мысли за 3 секунды.
**Читать**: `spec/calendar.md`, `spec/capture.md`, ADR-008/009 (с дополнением S5), решение S4.

## Тикеты-кандидаты
1. `Item` (event/task), подзадачи, RRULE, вычисление горизонта — домен + тесты (граница суток в часовом поясе пользователя!).
2. Экран задач по горизонтам, свайпы «готово/перенести».
3. Календарь: день/неделя/месяц, значок плановых трат.
4. `expectedCost` → плановая операция; `prepTask`; подтверждение после события; каскад при отмене.
5. Парсер фраз (по итогам S4), фикстура ≥ 60 фраз.
6. Быстрая запись: `/capture`, сохранение черновика до разбора, «Входящие» v2, manifest shortcuts + share_target.
7. Выгрузка в Google Calendar: очередь, идемпотентность по `faItemId`, напоминания; включение — только с разрешения пользователя (CLAUDE.md №3).
8. Read-only показ других календарей (инкрементальная авторизация).

## Готово, когда
- e2e «Театр»: фраза «театр сб 19:00 2х5000 драм, купить билеты до чт» → событие + prepTask + плановая трата в прогнозе → после события подтверждение → фактическая операция.
- Быстрая запись: от тапа по ярлыку до сохранения < 3 с на телефоне; черновик переживает убийство вкладки сразу после «Сохранить».
