# M3 — MVP-1 · Opus · middle · ветка `m3-mvp1`

**Цель**: пользователь вносит своё реальное состояние и начинает ежедневно записывать траты.
**Читать**: `spec/overview.md` (экраны), `spec/finance.md` F1–F4, `spec/nfr.md` N1/N4, ADR-006 (дополнение S3).

## Тикеты-кандидаты
1. Сервис курсов: источники из S3, кэш в Dexie, обновление > 12 ч, ручной курс, офлайн-метка.
2. Онбординг F1 (вход Google или пропуск, основная валюта, мастер счетов с быстрым добавлением строк).
3. Главная: капитал крупно (анимация счётчика ≤ 400 мс, `prefers-reduced-motion`), «доступно сейчас», запас прочности (заглушка «нужно 1 мес. истории», пока нет данных), FAB.
4. Форма расхода: минимум полей на первом экране (сумма → категория-чипы → счёт по умолчанию), «Повторить последнюю», шаблоны-чипы.
5. Форма дохода, перевода/обмена, сверки.
6. Лента операций: группы по дням, свайпы, отмена удаления 5 с, виртуализация.
7. Экран счетов по ликвидности.
8. Настройки: основная валюта, категории (CRUD), синхронизация (статус, ручной запуск, выход), JSON-экспорт/импорт.

## Готово, когда
- Сценарий e2e: онбординг 6 счетов в 3 валютах → 10 трат → перевод с обменом AMD→RUB → капитал совпадает с ручным расчётом.
- Ввод траты от тапа на «+» до сохранения ≤ 3 тапа + ввод суммы.
- Бюджеты N1 соблюдены (CI).
- Пользователь проверил на своём телефоне и дал «ок» на переход на основной аккаунт.
