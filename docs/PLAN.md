## Протокол сессии
1. Новая сессия: модель/effort по `MODELS.md` → «продолжай по PROGRESS.md».
2. Агент читает PROGRESS → тикет → `plan/<этап>.md` → нужные разделы spec.
3. Работа по тикетам: `implement` + `tdd`, ветка этапа, коммиты.
4. Длинный этап — `/compact` между тикетами; если этап не влез в сессию — PROGRESS обновляется как «этап в процессе, следующий тикет #N», затем `/clear`.
5. Конец этапа — контрольная точка из `CLAUDE.md` → напоминание о `/clear` и смене модели.
